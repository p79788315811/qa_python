## Проект: Автоматизация тестирования класса BooksCollector

## Цель проекта

Данный проект направлен на автоматизацию тестирования класса `BooksCollector`, обеспечивающего управление коллекцией книг и их жанрами. Основная цель — написание набора тестов, покрывающих основные функции класса, и обеспечение стабильной работы приложения.

## Реализованные тесты

В проекте реализованы следующие тесты:

- Проверка добавления новой книги в коллекцию.
- Установка и получение жанра книги.
- Удаление книги из коллекции.
- Работа с избранными книгами (добавление, удаление, проверка наличия).
- Проверка обработки ошибок (например, отсутствие книги в коллекции).

Всего выполнено **17 тестов**, покрывающих основные сценарии использования.

## Инструкция по установке и запуску тестов

### Требования

- Python версии >= 3.8
- Библиотека `pytest`
